# ☕ JavaLearn

אתר ללימוד Java למדעי המחשב (5 יח"ל) לפי תוכנית הלימודים של משרד החינוך:

- 🌱 **יסודות מדעי המחשב** – משתנים, קלט/פלט, תנאים, לולאות, פעולות, מחרוזות, מערכים, מערך דו-ממדי
- 🧱 **עיצוב תוכנה** – מחלקות ועצמים, toString ובנאים, הפניות, מערך עצמים, ירושה ופולימורפיזם
- 🌳 **מבני נתונים** – רקורסיה, יעילות, `Node<T>`, `Stack<T>`, `Queue<T>`, `BinNode<T>`

כולל תרגול בכל שיעור, משחק שלבים ("מסע ה-Java"), מצב אתגר ודף עזר.
ההתקדמות נשמרת בדפדפן.

האתר בנוי מ-HTML, CSS ו-JavaScript בלבד, ולכן אפשר לפרסם אותו ב-GitHub Pages בלי שלב בנייה.
